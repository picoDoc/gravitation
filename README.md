# Pygame Project

A simple Python game project using the pygame framework.  I'm going to try to reproduce [gravitation](https://demonstudios.com/gravitation.html)

## Prerequisites

- Python 3.6 or higher
- Git

## Development

This project uses a virtual environment to manage dependencies. Always activate the virtual environment before working on the project:

```bash
source venv/bin/activate
```

To deactivate the virtual environment when you're done:

```bash
deactivate
```

By default the game now runs in the browser using pygbag, to launch run:

```
pygbag main.py
```
